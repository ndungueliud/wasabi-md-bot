### 🚀 Deployment - One Click

#### 1. Fork This Repo
<a href="https://github.com/ndungueliud/wasabi-md-bot/fork"><img src="https://img.shields.io/badge/Fork-Repo-00FF41?style=for-the-badge" /></a>

#### 2. Get Pair Code (Termux)
```bash
pkg update && pkg upgrade -y
pkg install nodejs git -y
git clone https://github.com/ndungueliud/wasabi-md-bot
cd wasabi-md-bot
npm install
node index.js
# Enter 8 digit code in WhatsApp > Linked Devices > Link with phone number
